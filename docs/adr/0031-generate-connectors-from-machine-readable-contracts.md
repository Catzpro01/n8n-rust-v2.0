# Generate connectors from machine-readable contracts

A Connector Factory converts OpenAPI, GraphQL introspection, protobuf/gRPC reflection, AsyncAPI, and cURL examples into typed Declarative Node Definitions, pagination and rate-limit behavior, and credential templates. Generated connectors remain untrusted until previewed, tested, scanned, versioned, and locally signed, providing easy extension without requiring every integration to become handwritten Rust.

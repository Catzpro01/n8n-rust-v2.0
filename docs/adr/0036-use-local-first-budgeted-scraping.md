# Use local-first scraping with budgeted paid fallback

Scrape selection prefers local or free adapters while their measured success probability satisfies the Crawl Plan, then permits hosted Firecrawl, Bright Data, or Oxylabs only within hard request, bandwidth, money, and deadline budgets. Local browsers occupy the Heavy Orchestrator Lane and default to concurrency one on the initial VPS, keeping provider convenience and browser demand outside the daemon memory SLO.

# Measure superiority with an evidence scorecard

The project does not make an untestable claim of being better in every subjective dimension; it maintains an evidence scorecard for feature compatibility, constrained-host resources, 100,000 Activations, extension ergonomics, durability, replay, security, remediation, AI composition, scraping, Hub behavior, and import diagnostics. A superiority claim is earned only by repeatable acceptance tests or benchmarks against the pinned Compatibility Profile.

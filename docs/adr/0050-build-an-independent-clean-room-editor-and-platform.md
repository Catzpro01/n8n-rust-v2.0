# Build an independent clean-room editor and platform

The final product is an independently named clean-room platform with its own editor, server, visual identity, copy, assets, and implementation; it may preserve familiar workflow concepts and documented n8n import behavior but does not copy n8n source, enterprise files, icons, text, or trade dress. This supersedes the earlier private-hybrid and adapted-editor decisions because an independent product and licensable codebase now outweigh short-term UI parity speed.

Compatibility work uses public documentation, owner-created workflow exports, black-box observations, and independently authored conformance fixtures. Existing n8n packages may be user-installed external compatibility inputs under their own licenses, but are not redistributed or relicensed as part of the clean-room product.

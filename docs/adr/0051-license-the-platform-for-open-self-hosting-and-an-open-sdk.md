# License the platform for open self-hosting and an open SDK

Independently authored server and editor code use AGPL-3.0-or-later so network-deployed modifications remain available to their users, while Node SDKs, protocol and package schemas, client libraries, and examples use Apache-2.0 to maximize connector adoption with an explicit patent grant. Brand names and visual assets are separately reserved, and third-party compatibility inputs retain their own notices and licenses.

A future proprietary commercial license may be offered only where the project owns the necessary rights; external contributions require a documented contribution policy before dual licensing is attempted. Public or commercial release receives specialist legal review.

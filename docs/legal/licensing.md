# Licensing layout

- Server and independent editor: AGPL-3.0-or-later.
- Node SDK, protocol and package schemas, client libraries, and examples: Apache-2.0.
- Brand names, logos, and distinctive visual assets: separately reserved.
- Third-party dependencies and compatibility packages: their upstream licenses and notices.

The repository root license is the default for code not covered by a more specific directory license. Every source file and package manifest will carry an SPDX identifier. This design decision is not a substitute for legal advice before release.

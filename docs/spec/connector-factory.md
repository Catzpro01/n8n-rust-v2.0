# Connector Factory

Inputs may include OpenAPI, GraphQL introspection, protobuf and gRPC reflection, AsyncAPI, cURL, and reviewed examples. Outputs are versioned Connector Definitions with typed operations, credentials, pagination, retry safety, rate limits, Artifact handling, and generated contract tests.

Generation never installs directly into a Published Revision. A preview shows source provenance, inferred side effects, requested capabilities, unresolved ambiguity, tests, and the local signature that will identify the installed definition.

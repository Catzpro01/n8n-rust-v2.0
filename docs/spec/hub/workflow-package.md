# Workflow Package

A Workflow Package is declarative and content-addressed. It may carry workflow definitions, display metadata, screenshots, fixture data, contract tests, compatibility requirements, migrations, locked Node Definitions, Skill Sets, MCP contracts, permission and cost manifests, license records, checksums, SBOMs, and provenance attestations.

It may not contain credential values or require an installer to execute merely to inspect the package. Executable artifacts are quarantined until their source, digest, attestation, requested capabilities, and sandbox evidence satisfy local policy.

# Scrape Orchestrator

Scrape Orchestrator is a late product milestone built on HTTP Orchestrator, durable scheduling, Artifacts, Capability Grants, Secret Leases, and hard budgets. It supports native Rust HTTP and parsing, Firecrawl, Scrapy, Crawlee with Playwright, Bright Data, Oxylabs, and Camoufox through versioned Scrape Adapters.

A Crawl Plan selects Auto, Manual Pin, or Policy mode. Auto mode escalates only when classified evidence shows the current adapter cannot meet rendering, interaction, extraction, region, latency, compliance, or success requirements. The Causal Trace records selection scores, failure evidence, fallback, cost, and outputs.

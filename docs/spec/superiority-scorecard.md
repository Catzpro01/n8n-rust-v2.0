# Evidence-based superiority scorecard

The scorecard compares the active Compatibility Profile with repeatable fixtures and measurements. It covers public feature compatibility, constrained-host resource use, 100,000-Activation execution, custom-node authoring effort, recovery and replay, secret and network containment, remediation quality, AI composition and budgets, Scrape Orchestrator outcomes, Workflow Hub safety, and import diagnostics.

A dimension is marked superior, parity, partial, unsupported, or not comparable and links to evidence. No aggregate marketing score may hide an unsupported parity requirement.
